# Contributing Templates

1. Choose DocType profile or add one in `doctype_profiles.py`
2. Add theme if needed in `themes/registry.py`
3. Add components under `components/`
4. Run `python scripts/bootstrap_library.py` or create format folder manually
5. Set `metadata.json` with license and status
6. Validate and open PR

Draft templates must not claim legal compliance for any country unless reviewed and documented.
