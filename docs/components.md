# Components

60 reusable Jinja partials live under `erpnext_print_pack/components/`.

Categories: headers, party blocks, item tables, totals, tax summaries, QR, barcode, signatures, payment blocks, footers, terms.

Components are assembled at generation time into complete Print Format HTML files.

See `erpnext_print_pack/components/registry.py` for the full list.
