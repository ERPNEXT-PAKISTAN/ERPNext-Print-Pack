# Themes

24 neutral themes ship with dedicated CSS under `erpnext_print_pack/themes/`.

Themes include Minimal, Modern, Corporate, Executive, Material, Elegant, Compact, Clean, Technical, Industrial, Manufacturing, Retail, Wholesale, Professional Blue/Green, Monochrome, Soft Gray, Premium, Landscape, Thermal, Bilingual, Tax Focused, QR Enabled, Barcode Enabled.

No trademarked company branding is included.
